<p><i>SPIC</i> (kurz für Simple Play Integrity Checker) ist eine einfache Android-App, die die Verwendung der PlayIntegrity API sowie der veralteten SafetyNet Attestation API demonstriert.</p><p>Das von den APIs empfangene Integritätsurteil kann lokal auf dem Gerät überprüft oder an einen Remote-Server gesendet werden, damit es dort validiert werden kann. Die Remote-Server-Implementierung muss vorerst selbst gehostet werden.</p><p>Die App ist OpenSource und der Quellcode der Android-App sowie die Serverimplementierung sind auf Github zu finden (siehe <code>/herzhenr/SPIC-android</code> und <code>/herzhenr/SPIC-server</code>).</p>
