<p><i>quickrotate</i> is a useful uitlity for ONYX BOOX Eink devices. It provides several quick actions to be added in top system panel.</p><p><br><b>Features:</b></p><ul><li>Rotate screen to specifid direction</li><li>Open recent task screen</li><li>Take screenshot of current screen</li><li>Switch Screen Refresh mode between Normal and A2 mode (v1.5.0)</li><li>Separate buttons for Noraml/Speed/A2 mode (v1.6.0)</li></ul><p>Usage instructions can be found in the project's Readme.</p>
