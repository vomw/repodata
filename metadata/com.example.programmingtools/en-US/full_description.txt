<p><i>QRCodeGenius</i> is a simple, user-friendly tool designed to generate QR codes from text input. It provides an efficient way for users to create QR codes right from their Android devices, which can then be saved and shared.</p><p><br><b>Features:</b></p><ul><li><b>Customizable QR Code Generation:</b> Converts user input text into QR codes with options for size and color customization.</li><li><b>User-Friendly Interface:</b> Designed for ease of use, providing a straightforward and intuitive user interface.</li><li><b>Save and Preview Functionality:</b> Users can preview the generated QR code and save it as an image on their device.</li><li><b>Additional Text Feature:</b> Ability to add extra text beneath the QR code for descriptive purposes.</li></ul>
