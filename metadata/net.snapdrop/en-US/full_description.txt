<p><i>Snapdrop</i> can be used to transfer files between phones and laptops on same wifi. The app is a wrapper around the <a href='https://github.com/RobinLinus/snapdrop' target='_blank' rel='nofollow'>snapdrop project</a> using webview and some javascript interface for downloads.</p><p>Using <i>Snapdrop</i> is as easy as this:</p><ol><li>Open Snapdrop app (or visit www.snapdrop.net).</li><li>Tap on a device name and select files to transfer.</li><li>Make sure both devices are connected to <b>same</b> Wifi or hotspot.</li></ol><p><b>NOTE:</b> You can create hotspot on one phone, connect other devices to it and then transfer files using the app or the website.</p><p><br><b>KNOWN ISSUES:</b></p><ul><li>Might not work with VPN enabled on your devices.</li><li>The app renames all the downloaded files to something starting with Snapdrop_. You'll find these files in your Downloads folder.</li><li>There are times when it just won't work and there's nothing anyone can do about it. Sorry. Please refresh, restart or try again later.</li></ul><p>If the problem doesn't go away, <a href='https://github.com/robinlinus/snapdrop/issues' target='_blank' rel='nofollow'>report your issue</a>.</p><p><br><b>CREDIT:</b></p><p>This app and logo is based on the free and open source <a href='https://github.com/robinlinus/snapdrop' target='_blank' rel='nofollow'>Snapdrop project by Robin Linus</a>.</p><p><br><b>APP:</b></p><p>Developed by Tanuj. Free and <a href='https://github.com/tanujnotes/snapdrop' target='_blank' rel='nofollow'>open source</a>. No login, no ads.</p><p><br><b>FEATURE REQUESTS:</b></p><p>Features are chosen very carefully because complexity grows exponentially with each other feature. We focus very narrowly on a single use case: instant file transfer. Please don't be sad if we decline your feature request for the sake of simplicity. Thank you for understanding.</p><p><br><b>PRIVACY:</b></p><p>None of your files are ever sent to any server. Files go directly from one device to another and are encrypted by default.</p>
