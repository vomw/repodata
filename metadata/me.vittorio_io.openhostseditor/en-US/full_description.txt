<p><i>Open Hosts Editor</i> is a free and open source application to edit the <code>/etc/hosts</code> file for Android devices.</p><p>Your device <b>must be rooted</b>. Not all devices have the hosts file in the same path, so it might not work on yours. You can submit an issue so that I can investigate.</p><p><b>Note:</b> the app's repo seems to be no longer maintained, so there won't be further updates. Please report should the app no longer work.</p>
