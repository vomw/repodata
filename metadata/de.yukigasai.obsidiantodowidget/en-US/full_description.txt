<p><i>Obsidian</i> provides a widget to display an interactive todo list from a markdown file.</p><p>After having the app installed, start it once to grant it the storage permissions – then the widgets are ready to be used.</p><p><br><b>Setup:</b></p><ol><li>Select widget from the widget list</li><li>Drag to Homescreen</li><li>Enter the Obsidian Vault name to use</li><li>Configure the file to use</li><li>Press "Select" to define the folder where the file(s) is/are stored.</li><li>Enter the single filename or enter a date pattern</li><li>If you want to limit the the tasks to a specific header enter the header name into the "Header" field</li><li>If you want to include sub Headers check the "Include Sub Headers" switch</li><li>Press Create</li></ol>
