<p>This is an MPV Remote application for controlling your media player.</p><p>Kodi not renders properly some ASS/SSA subtitles some anime have overanimated subtitles. Kodi not likes it much. MPV plays everything fine, but did not find a proper featureful remote app.</p><p><br><b>Functions:</b></p><ul><li>Basic media controls,</li><li>Open Youtube videos (youtube-dl required),</li><li>Open files from your host computer, network storage also supported,</li><li>Audio & Subtitle track selector,</li><li>Playlist handling,</li><li>Media file info,</li><li>Media collection handling,</li><li>Media status time can be stored on host machine. You can continue playback where you left off,</li><li>Open videos from Youtube app by using share function,</li><li>Open online streams from other apps</li></ul><p>Please see the project's documentation for setup instructions.</p>
