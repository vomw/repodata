<p><i>MiDoze</i> is the easiest way to download firmwares for Xiaomi wearables. You can even use it with older Android devices: it supports at least Android 4 (aka Ice Cream Sandwich), though for full compatibility you'll need at least Android 5.</p><p><br><b>Features:</b></p><ul><li>User-friendly GUI</li><li>Material Design 3</li><li>English and Russian GUI languages</li><li>Light and Dark themes</li><li>Shortcuts (since 1.1.0)</li><li>Explore firmwares feed</li><li>Adaptive feed column count (since 4.0.0)</li><li>Feed cache (since 4.0.0)</li><li>Search a device using the SearchView</li><li>Favorites (since 2.0.0)</li><li>Request host chooser</li><li>Request region chooser</li><li>Full languages names in response</li><li>Built-in download provider</li><li>Compose custom requests with Custom request in settings</li><li>Update checker (since 2.1.0)</li><li>Bottom navigation bar (since 4.0.0)</li></ul>
