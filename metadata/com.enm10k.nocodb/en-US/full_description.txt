<p><i>NocoDB Mobile</i> is a prototype Android/iOS client for <a href='https://github.com/nocodb/nocodb' target='_blank' rel='nofollow noopener'>NocoDB</a>, an open-source alternative to Airtable.</p><p>This project aims to make NocoDB's core functionality easily accessible from mobile devices. It is currently under development, and my immediate goals are to support the basic functionality of the Grid View feature of NocoDB and improve stability.</p>
