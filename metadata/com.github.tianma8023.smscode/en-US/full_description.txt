<p><i>SmsCode</i> is a non-xposed version of <a href='https://github.com/tianma8023/XposedSmsCode' target='_blank' rel='nofollow'>XposedSmsCode</a>. It can recognize, parse SMS code and copy it to clipboard when a new message arrives, it can also auto-input SMS code.</p><p><b>Attention:</b> This module is suitable for AOSP ROM, it may not work well on other 3rd-party ROM.</p><p><br><b>Features:</b></p><ul><li>Copy verification code to clipboard when a new message arrives.</li><li>Show toast when a SMS verification code is copied.</li><li>Show notification when code SMS parsed.</li><li>Custom keywords about verification code message (regular expressions allowed).</li><li>Custom SMS code match rules.</li><li>Mark verification code SMS as read (experimental).</li><li>Delete verification SMS when it been extracted successfully (experimental).</li><li>Block code SMS message notification (experimental).</li><li>Auto-input SMS code.</li><li>Various theme color to choose.</li></ul>
