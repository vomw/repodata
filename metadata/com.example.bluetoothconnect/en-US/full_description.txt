<p><i>BluetoothConnect</i> lets you use your Android device as A Bluetooth Keyboard, supporting OTG as well.</p><p><br><b>How to use</b></p><ol><li>pair Android and other devices, like Windows or iPhone to get the device name</li><li>forget this Android on Windows; no need for iPhone</li><li>open this app, choose Windows or iPhone's name to connect</li><li>if it's Windows, it will pop pair-dialog up, pair it; no need for iPhone</li><li>OTG connect this Android with wired keyboard, choose aosp English keyboard as input method on Android</li><li>no need to repeat above steps for reopen this app, but if the PC's changed, it needs to repeat it again; no need for iPhone</li></ol><p>More details and hints can be found in the project's Readme.</p>
