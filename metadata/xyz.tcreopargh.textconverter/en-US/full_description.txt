<p><i>Text Converter</i> is a utility to deal with texts – either manually entered, or loaded from a file. You can do simple search-and-replace (or use regular expressions for that), count characters, shuffle, inverse, encrypt and more. It even supports formatting of Java, JSON and HTML.</p><p>The text is typed manually in the app or copied from anywhere text/strings need processing. For example, select MD5 hashing in menu, enter a string, press the executing button and get the result. It’s mainly developers or digital enthusiasts that may use the app. Without this, the current open source solution on Android is terminal emulators with corresponding packages installed, which is obviously not friendly to end users.</p><p>The functions that have been implemented are:</p><ul><li>String search (optional regular expression matching)</li><li>String replacement/removal (regular expression matching is optional)</li><li>Text segmentation, scramble, and sort (if the text is a string of numbers, it can be sorted according to the size of the number)</li><li>AES encryption and decryption</li><li>Java code formatting, JSON formatting, HTML formatting</li><li>Base64 encoding/decoding, MD5 digest generation</li><li>Morse code encoding/decoding</li><li>String reversal, segmentation, indentation, labeling, case conversion, batch copy</li><li>Markdown preview</li><li>Generate random numbers and text draws in custom formats</li><li>HTML/XML/JSON/Java/CSV/ECMAScript escape and inversion</li><li>Escape regular expression</li><li>Read/write from file</li><li>Get webpage source code</li><li>Calculate string similarity</li><li>Custom regular expression</li><li>Generate random string</li><li>Generate pinyin from Chinese characters</li><li>Undoable edit</li><li>Remove blank characters at both ends of the string</li><li>Reference documents with regular expressions</li></ul><p><b>Note:</b> the app's repo is no longer maintained, so there won't be any further updates.</p>
