<p><i>Verifit</i> is a simple minimalist fitness tracker that I made mainly for myself. The UI is heavily inspired by FitNotes. It’s purpose is to replace the traditional paper and pencil method for tracking progressive overload. Since I made this with the primary user in mind being myself, it is not fully featured yet, but I do have future plans for adding extra features over time. This is my first attempt so suggestions and code improvements are always welcome.</p><p><br><b>Features:</b></p><ul><li>Exercise tracking</li><li>Create custom exercises</li><li>Edit, delete exercises</li><li>Easily import &amp; export in csv format</li><li>Basic analysis of workout data</li><li>Visualization of workout data</li><li>Volume, actual 1RM, estimated 1RM, and other stats tracking</li><li>Includes simple rest timer</li></ul>
