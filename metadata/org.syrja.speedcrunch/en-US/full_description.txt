<p><i>SpeedCrunch</i> is a high-precision scientific calculator supporting expression editing, history stack, unit conversions, radix systems, complex numbers and user defined variables.</p><p><br><b>Features:</b></p><ul><li>Calculations with up to 50 digits of precision</li><li>History stack with value or expression recall</li><li>Expression editing with system virtual keyboard</li><li>Fixed decimal, scientific or engineering formats</li><li>Decimal, binary, octal and hexadecimal bases</li><li>Built-in functions, constants and units with search</li><li>User defined variables and functions</li></ul><p>Usage instructions can be found at the project’s Github presence.</p>
