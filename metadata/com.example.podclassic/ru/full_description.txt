<p><i>PodClassic</i> имитирует iPod Classic. Приложение локализовано для китайского и английского языков и интуитивно понятно в использовании:</p><ul><li><b>Колесо:</b> Сдвиньте красную часть для перемещения курсора вверх и вниз.</li><li><b>Кнопка:</b> Нажмите черную среднюю кнопку для подтверждения</li><li><b>Кнопка:</b> Нажмите и удерживайте среднюю кнопку, чтобы собрать песни/папки, содержащие песни/альбомы/артистов, и воспроизвести их в коллекции</li><li><li><b>Значки колесика:</b> Четыре значка функционируют, как показано на рисунке</li></ul><p><b>Примечание:</b> репо приложения и аккаунт на Github были удалены, поэтому это приложение больше не будет получать обновления.</p>
