<p><i>Engine</i> is a software that allows you to use your phone as a virtual joystick, allowing you to play racing games like <a href='https://store.steampowered.com/app/244210/_Assetto_Corsa/' target='_blank' rel='nofollow noopener'>Assetto Corsa</a> and <a href='https://store.steampowered.com/app/227300/Euro_Truck_Simulator_2/' target='_blank' rel='nofollow noopener'>Euro Truck Simulator 2</a> more comfortably without a steering wheel.</p><p><b>Features:</b></p><ul><li>Mapping available data to virtual joystick data</li><li>Designed using Material 3 guidelines</li><li>The Screens and UI elements are built entirely using Jetpack Compose</li><li>Easy-to-use widget editor</li><li>Several different presets can be set for widgets</li><li>Light and dark color themes supported</li><li>Ability to map the phone's volume keys as buttons to the game (e.g. you can manipulate the volume keys to upshift and downshift your car)</li><li>Language support for Chinese & English</li></ul>
