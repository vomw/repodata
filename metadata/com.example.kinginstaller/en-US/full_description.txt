<p><i>KingInstaller</i> lets you install packages "as Google Play Store", to work around restrictions. Useful (not only) for <i>Android Auto</i>.</p><p>Once you have this app installed, you need to grant it two permissions from within <i>Settings › Apps</i>: the permission to <i>Allow access to manage all files</i> (via <i>Special app access › All files access › KingInstaller</i>), and via <i>all apps › KingInstaller › Install unknown apps</i> check <i>Allow from this source</i>.</p><p><br><b>Usage</b></p><ol><li>If the <code>.apk</code> is already installed: Uninstall it first</li><li>Open <i>KingInstaller</i></li><li>Click <i>Select file ...</i> and select the <code>.apk</code> to install.¹</li><li>Click <i>Install as king</i>¹</li><li>Wait for text-field with <code>.apk</code> file-path to clear</li><li>Validate if package installed "as Google Play Store"¹</li></ol><p>¹ For optional settings, as well as the verification steps, please see the app's repo.</p>
