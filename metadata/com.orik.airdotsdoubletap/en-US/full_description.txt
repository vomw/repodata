<p><i>Airdots Double-Tap</i> adds the functionality to plays next/previous songs on double-tap (On most earphones) instead of opening virtual assistant.</p><p><br><b>How to use (Refer to the screenshots):</b></p><ul><li>Double tap the earbuds</li><li>The device will ask you with which app to complete the action</li><li>Select ’always with this app’</li><li>Enjoy</li></ul><p><br><b>Play previous song:</b></p><ul><li>Pause the media with one tap</li><li>Once the media is paused double tap</li></ul><p><br><b>Skip Media Backwards twice:</b></p><ul><li>In most media players When the song is not at the start and the user skip backwards the song rewind to the start instead of skipping back to the previous song</li><li>This options make the 'Play Previous song' functionality skip backwards twice in order to 'force' the media player to go to previous song</li></ul>
