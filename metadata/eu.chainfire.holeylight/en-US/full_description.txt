<p><b>100% Free - 100% GPLv3 Open Source - No ads - No tracking - No nags - Optional donation</b></p><p><b>Holey Light</b> is a LED emulation app. It animates the edges of the camera cut-out (AKA punch-hole) as replacement for the sadly missing LED on many modern devices.</p><p>Additionally, it provides a notification display for when the screen is "off", replacing - or working in conjunction with - the <b>Always-On Display</b> feature. As this display is not around the camera hole, it is aptly named the <b><i>Un</i>holey Light</b>.</p><p>Supports all Samsung devices with in-screen camera hole, and several Google Pixels.</p><p><br><b>Features</b></p><ul><li>Emulates notification LED</li><li>Four different display modes: <i>Swirl, Blink, Pie, Unholey Light</i></li><li>Configurable animation size, position, and speed</li><li>Customizable color for each notification channel</li><li>Selects initial notification color by analyzing dominant color of app icon</li><li>Displays during screen &quot;off&quot;, sub-1% battery use per hour in <i>Unholey Light</i> mode</li><li>Separate configuration modes for different power and screen states</li><li>Ability to mark notifications as seen based on various triggers</li><li>Respects Do-Not-Disturb and AOD schedules</li><li>Can hide AOD completely, partially, and/or keep the clock visible</li></ul><p><br><b>Setup</b></p><p>Initial setup can be a bit tricky for a first-time user, but a setup wizard is included that guides you through the process.</p><p><br><b>Permissions</b><p>This app absolutely requires several permissions to be able to function. If you are concerned about that, you can always check out the source code (or not use the app).</p><ul><li>Accessibility: the app needs an accessibility service to render the emulated LED on-screen, and track the correct position to display in screen &quot;off&quot; mode.</li><li>Notifications: a notification service is needed to be able to know about the notifications before we can show them</li><li>Companion device: in a weird quirk of Android, this permission is required to be able to read the wanted LED color of notifications</li><li>Battery optimization exemption: without this, Android would randomly disappear our emulated LED</li><li>Foreground service: both an accessibility and notification service are used as described above</li><li>Wake lock: you decide when and how the app draws on the screen, sometimes this requires making sure the CPU isn’t sleeping</li><li>All package access: we render other app’s icons and access some of their base information to be able to differentiate different notifications from each-other</li></ul>
