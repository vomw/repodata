<p><i>OneClipboard</i> is a collection of collaborative apps to automatically sync clipboards on remote devices. This is the server part. It has no knowledge-of or access-to any clipboards, it simply relays text between connected clients.</p><p>Any number of clients can connect to a single server. All clients that are connected to the same server, and identify with the same username/password combination, will effectively share a single clipboard – and an update to any one, will immediately update all. All clipboard text communicated between devices is encrypted over the network.</p><p>A corresponding desktop variant is available as well.</p>
