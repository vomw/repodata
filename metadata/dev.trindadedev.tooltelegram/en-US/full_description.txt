<p>This is a simple application to send messages to telegram with bot.</p><p><br><b>Features:</b></p><ul><li>Send Message for Groups, topic groups, channels, and normal chats</li><li>Change app Theme</li></ul><p><b>How to use: How to get the bot token?</b></p><ul><li>to get the bot token you can create a bot at t.me/botfather and it will give you the bot token. How to get chat id?</li><li>you can use t.me/raw_data_bot to get the id of the chat, group etc... How to get topic id?</li><li>Normally, the topic id is in the topic link, like this link: <code>https://t.me/robokinc/6998</code>, in this case the topic id is 6998.</li></ul>
