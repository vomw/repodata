<p><i>DroidVim</i> is a Vim clone text editor ported for Android. Vim 8 (huge version, multi language), grep, diff and ctags are ready to use.</p><p><b>Features:</b></p><ul><li>External storage support - External SD card, USB memory, GoogleDrive, Dropbox, etc. (Requires Android 4.4 and up)</li><li>Special Keys - Esc, Ctrl, Tab, Arrow keys and more.</li><li>Direct input - Disabling predictive text and/or auto correction for normal mode.</li><li>Clipboard - Clipboard commands ("*p "*y) are supported.</li><li>Custom Font - Use your favorite monospaced font.</li><li>Touch to move - Touch, swipe, flick to move cursor.</li><li>Multi language - Vim with multi byte option, iconv and multi language messages.</li></ul><p><b>Extra features (in-app purchase):</b></p><ul><li>Git - Version Control System.</li><li>Python - Programming language.</li></ul>
