<p><i>PWS Watcher</i> allows you to monitor the data generated by <a href='https://en.wikipedia.org/wiki/Weather_station#Personal_weather_station' target='_blank'>PWS</a>. The application allows the monitoring of multiple weather stations simultaneously. It works with …</p><ul><li>realtime.txt generated by Cumulus MX</li><li>clientraw.txt generated by Weather Display</li><li>daily.csv generated by Ambient Weather</li><li>XML file generated by WeeWX</li></ul>
