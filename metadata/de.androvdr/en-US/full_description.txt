<p><i>AndroVDR</i> is an Android application to control the Linux based <a href='http://tvdr.de/' target='_blank' rel='nofollow'>VDR</a>.</p><p><b>Features:</b></p><ul><li>remote control</li><li>views for channels, timer, recordings, EPG</li><li>search in EPG (epgsearch plugin in VDR required)</li><li>display channel logos (not included)</li><li>adjustable text size</li><li>2 different layouts</li><li>1 additional, user definable, layout</li><li>layout change by "swipe" (Android 2.1)</li><li>control with gestures</li><li>volume control with HW-Keys</li><li>control multiple VDR’s</li><li>SSH tunneled connection over internet</li><li>WOL over WLAN or internet (long click on power-on)</li><li>App2SD</li><li>Live TV, needs streamdev server and an external player, such as VPlayer</li></ul><p><b>Note:</b> This is a fork of the <a href='https://code.google.com/archive/p/androvdr/' target='_blank' rel='nofollow'>original app</a> (were development stopped at v1.5 in 2012). It contains some adjustments to make the app working again with CM13+ (see <a href='https://www.vdr-portal.de/forum/index.php?thread/128806-androvdr-st%C3%BCrzt-ab-neukompilieren-hilft/' target='_blank' rel='nofollow'>this Forum thread</a>) – and currently it seems to work at least up to Android 8.</p><p>Though being a bit old, it seems to be in high demand and favored over newer apps, so I’ve made the exception to add it to this repo nevertheless, on special request by <a href='https://mastd.racing/@STP_KITT' target='_blank'>@STP_KITT</a>. Updates are rather unlikely, though.</p>
