<p>This application is open source software for quick and easy installation of the operating system (OS) GNU/Linux on your Android device.</p><p>The application creates a disk image on a flash card, mounts it and installs an OS distribution. Applications of the new system are run in a chroot environment and working together with the Android platform. All changes made on the device are reversible, i.e. the application and components can be removed completely. Installation of a distribution is done by downloading files from official mirrors online over the internet.</p><p><b>The application requires superuser rights (ROOT).</b></p>
