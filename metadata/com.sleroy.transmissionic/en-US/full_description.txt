<p><i>Transmissionic</i> is a free multi-platform remote for Transmission Daemon built with Ionic and Vue.js. It can be used as <a href='https://github.com/transmission/transmission/wiki/Web-Interface' target='_blank' rel='nofollow noopener'>Web Interface</a>, Android/iOS app and Windows/Linux/macOS program.</p><p><br><b>Main features</b></p><ul><li>Manage multiple servers</li><li>Add torrent from local file or magnet link</li><li>Drag & drop torrent file</li><li>Magnet protocol support</li><li>Start/stop/reannounce/verify/delete one or more torrents</li><li>Modify torrent's options</li><li>Set the location of a torrent</li><li>Select and rename torrent's files</li><li>Edit tracker list</li><li>View the list of peers with country flags</li><li>Sort torrents by trackers</li><li>Open files in explorer</li><li>Use presets when adding torrents</li></ul>
