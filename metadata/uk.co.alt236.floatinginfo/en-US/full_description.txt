<p><i>Floating Info</i> is an Android application that displays the following in a system overlay window:</p><ul><li>The application name, package name and process id (except on Nougat+) of the application which is currently in the device’s foreground</li><li>The Global CPU utilisation with a per-core breakdown - This is not foreground application specific.</li><li>Memory usage breakdown for the currently foregrounded process - except on Nougat+ (read the notes for the caveats).</li><li>Netork information like connection type, proxy status and IP address(es). Both IPv4 and IPv6</li></ul><p>For screenshots and more, please visit <a href='https://github.com/alt236/Floating-Info---Android' target='_blank' rel='nofollow'>the project’s Github presence</a>.</p><p><b>Note:</b> the app's repo is no longer maintained, so there won't be any further updates. It is still <a href='https://codeberg.org/IzzyOnDroid/EverythingElse/issues/15#issuecomment-8331984'>partly working</a>, but one can disable the non-working parts.</p>
