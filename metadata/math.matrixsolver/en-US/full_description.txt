<p><i>MatrixSolver</i> is an educational application for solving linear algebraic equation (SLAE) systems. MatrixSolver allows the user to:</p><ul><li>familiarize yourself with the theoretical part (SLAE, system matrix, SLAE solution methods);</li><li>consider examples of specific problem-solving;</li><li>solve SLAE by Gauss, Gauss-Seidel, Jacobi (single- and multithreaded);</li><li>Transmit SLAE matrices through files, QR codes, and the Internet (using the Pastebin API);</li></ul><p>The first launch of the application clearly demonstrates the functions of the buttons. To view the application again, go to the Settings section, Button Assignment.</p><p>For SLAE solution user must form a table with empty cells and enter elements of each equation in each line:</p><li>coefficients for unknown (x1, x2, etc.);</li><li>free member</li></ul><p>and press the "=" button.</p><p>Answer is presented in the form of found SLAE roots and a detailed solution.</p><p>The found roots are substituted in each equation and the difference module is calculated the left and right parts of each equation. The sum of these modules is calculated and displayed on the screen as "Error".</p><p>Additional parameters, such as the accuracy of the solution, the maximum number of iterations, are specified in the Settings.</p><p><b>Note:</b> the app's repo is no longer maintained, so there won't be further updates.</p>
