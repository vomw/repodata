<p><i>ExtClipboardManager</i> is an enhanced clipboard manager. It is to inject the code when ClipboardService starts, and intercept and mark the key methods such as setPrimaryClip before or after they are executed.</p><p><br><b>Features:</b></p><ul><li><b>Timeout auto-clear clipboard:</b> customizable time setting in seconds</li><li><b>provide application whitelist and blacklist mode:</b> whitelist mode in the whitelist application will not trigger the clear clipboard operation; blacklist mode in the blacklist application will trigger the clear clipboard operation</li><li><b>Text exclusion function:</b> text matching the rules will not be automatically cleared</li></ul><p><b>Caution:</b></p><ul><li>Remember to check the system frame</li><li>Input method may read the content of the clipboard several times after cutting, whitelist mode is recommended to add the input method to the whitelist, otherwise the number of times read is easily exhausted by the input method.</li><li>In some cases, getPrimaryClip will not be triggered to read the clipboard, but the application can still read the clipboard, you may need to look at the source code to know what the reason is.</li><li>Currently (probably) only available for Android 12+</li></ul>
