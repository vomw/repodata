<p><i>Kõnele service</i> is an Android app that offers a speech-to-text service to other apps, in particular to <a href='https://f-droid.org/packages/ee.ioc.phon.android.speak/' target='_blank'>Kõnele</A>. It implements SpeechRecognizer, backed by an open source speech recognition server software named <a href='https://github.com/alumae/kaldi-gstreamer-server' target='_blank' rel='nofollow'>Kaldi GStreamer server</a>.</p>
