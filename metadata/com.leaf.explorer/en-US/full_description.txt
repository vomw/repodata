<p><i>Leaf Explorer</i> is an advanced file manager/explorer with many features.</p><p><b>Main Features:</b></p><ul><li>File Manager</li><li>File Transfers (like SHAREit)</li><li>txt Editer</li><li>Music Player (with Notification and Popup player).</li><li>Image Viewer.</li><li>Recent File (in beta trial).</li><li>And many more.</li></ul><p><b>File Sharing features:</b></p><ul><li>Pause, resume and reconnect transfers</li><li>Share large files</li><li>Share all kinds of content, video, photo, music and app libraries</li><li>No Internet connection is required: Set up a hotspot and connect to it using a QR code</li><li>Share between multiple devices at the same time</li><li>Exchange texts of any kind and save them to Leaf Explorer</li><li>Share folders for backup and other purposes</li><li>Light UI: Works faster than its rivals on low-end devices</li><li>Speed</li><li>oriented: Minimal UI optimized for speed</li><li>Advanced features: Network change handling, choose network based on measured speed</li></ul><p><b>Note:</b> the code repository of this app has been archived on 2022-12-27, and meanwhile is gone entirely including its Github account, so there won't be any updates to this app.</p>
