<p><i>Service Browser</i> (aka Bonjour Browser) is a utility that discovers all Bonjour services registered in a network and resolves meta-information about them, including IP addresses and port.</p><p>🚀 There are few more things:</p><ul><li>If service is web server you can open link in one-click.</li><li>Furthermore, you can mark domain as favourite and create shortcut for it on your desktop.</li></ul>
