<p><i>Service Browser</i> (auch bekannt als Bonjour Browser) ist ein Dienstprogramm, das alle in einem Netzwerk registrierten Bonjour-Dienste erkennt und Metainformationen darüber auflöst, einschließlich IP-Adressen und Port.</p><p>🚀 Es gibt noch einige Dinge:</p><ul><li>Wenn der Dienst ein Webserver ist, können Sie den Link mit einem Klick öffnen.</li><li>Außerdem können Sie die Domain als Favorit markieren und auf Ihrem Desktop eine Verknüpfung dafür erstellen.</li></ul>
