<p><i>GnuCash Mobile</i> is an application for keeping track of GnuCash transactions on the go.</p><p><b>Note:</b> this app is not meant to be a standalone implementation of GnuCash. Rather, it’s a simple tool for recording transactions as they happen that also allows you to export in a GnuCash-compatible format (CSV).</p><p><br><b>Capabilities:</b></p><ul><li>Import a set of accounts (these should be exported from a valid GnuCash instance; <i>File › Export › Export Account Tree to CSV…</i>)</li><li>Create transactions a GnuCash-compatible, double-bookkeeping fashion</li><li>Export said transactions for import into a standalone GnuCash instance (<i>File › Import › Import Transactions from CSV…</i>). Use the „GnuCash Export Format“.</li><li>Set favorite debit and credit accounts for pre-populating transaction fields.</li></ul>
