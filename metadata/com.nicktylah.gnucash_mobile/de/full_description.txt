<p><i>GnuCash Mobile</i> ist eine Anwendung zum Verfolgen von GnuCash-Transaktionen unterwegs.</p><p><b>Hinweis:</b> Diese Anwendung ist nicht als eigenständige Implementierung von GnuCash gedacht. Es handelt sich vielmehr um ein einfaches Tool zur Aufzeichnung von Transaktionen, das auch den Export in ein GnuCash-kompatibles Format (CSV) ermöglicht.</p><p><br><b>Funktionen:</b></p><ul><li>Importieren einer Reihe von Konten (diese sollten aus einer gültigen GnuCash-Instanz exportiert werden; <i>Datei › Export › Kontenbaum nach CSV exportieren…</i>)</li><li>Transaktionen in einer GnuCash-kompatiblen, doppelten Buchführung erstellen</li><li>Exportieren dieser Transaktionen zum Import in eine eigenständige GnuCash-Instanz (<i>Datei › Importieren › Transaktionen aus CSV importieren...</i>). Das „GnuCash Export Format“ verwenden.</li><li>Festlegen bevorzugter Soll- und Habenkonten für das Vorbefüllen von Transaktionsfeldern</li></ul>
