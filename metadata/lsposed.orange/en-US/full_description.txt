<p><i>Orange</i> is a Xposed module that support to specify orientation per app, which is useful for some app that need specified orientation to get better experience (such as MAME4droid).</p><p><b>Note:</b> The module config uses content provider, which needs the permissions of <code>autostart</code> and <code>running in the backgraound</code>, otherwise it will not work properly.</p><p>After installing the module, set up these permissions via app info setting page.</p>
