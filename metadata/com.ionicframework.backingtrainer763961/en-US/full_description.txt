<p><i>Backing Trainer</i> is an application to joy with your soloist instrument while listening a backing track. The application is fully Free in both senses.</p><p>For animated screenshots, please see the <a href='https://github.com/spheras/backingtrainer' target='_blank' rel='nofollow noopener'>project’s Github page</a>. Further information, e.g. how to include new compositions, can be found in <a href='https://github.com/spheras/backingtrainer/wiki/' target='_blank' rel='nofollow noopener'>the project’s wiki</a>.</p>
