<p>This is a companion app for your self-hosted Portainer service. It offers the convenience to manage your containers from your android device.</p><p>To use the app:</p><ul><li>You need to have a Portainer service up and running.</li><li>You need to have setup an username and password.</li><li>You can use your local URL address (ex. <code>http://192.168.1.15:9000</code>), or external URL (ex. <code>https://myexampledomain.com/portainer</code>)</li></ul><p>Features include:</p><ul><li>Dark Theme</li><li>View current state of docker containers</li><li>Start / stop docker containers</li><li>Monitor container logs (can be accessed by long pressing on any container card)</li><li>View container details (can be accessed by clicking on any container card)</li><li>Delete container</li><li>Switch between multiple Docker endpoints on the same Portainer server</li><li>Switch between multiple Portainer servers</li></ul><p>Note:</p><ul><li>Only Docker service is supported.</li><li>This app is in no way or form affiliated with the official Portainer project.</li></ul>
