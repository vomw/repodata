<p>Dies ist eine Begleit-App für Ihren selbst gehosteten Portainer-Dienst. Es bietet den Komfort, Ihre Container von Ihrem Android-Gerät aus zu verwalten.</p><p>So verwenden Sie die App:</p><ul><li>Sie müssen einen Portainer-Dienst in Betrieb haben.</li><li>Sie müssen einen Benutzernamen und ein Passwort eingerichtet haben.</li><li>Sie können Ihre lokale URL-Adresse (z. B. <code>http://192.168.1.15:9000</code>) oder eine externe URL (z. B. <code>https://myexampledomain.com/portainer</code>) verwenden.</li></ul><p>Features sind:</p><ul><li>Dunkles Thema</li><li>Aktuellen Status von Docker-Containern anzeigen</li><li>Docker-Container starten / stoppen</li><li>Containerprotokolle überwachen (kann durch langes Drücken auf eine beliebige Containerkarte aufgerufen werden)</li><li>Containerdetails anzeigen (kann durch Klicken auf eine beliebige Containerkarte aufgerufen werden)</li><li>Container löschen</li><li>Wechseln Sie zwischen mehreren Docker-Endpunkten auf demselben Portainer-Server</li><li>Wechseln Sie zwischen mehreren Portainer-Servern</li></ul><p>Hinweis:</p><ul><li>Nur der Docker-Dienst wird unterstützt.</li><li>Diese App ist in keiner Weise mit dem offiziellen Portainer-Projekt verbunden.</li></ul>
