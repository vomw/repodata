<p>This app was originally just created for myself to make some development tasks a bit easier. I’ve released it to the app store hoping that someone else might find it useful too.</p><p>Using this app you can see which resource qualifiers that are being used, which system features that are available, and see details about the display and its sizes.</p><p>Also I wanted to create an app where everything I needed was just one click away. The full list of features:</p><ul><li>See resource qualifiers in use</li><li>See available system features</li><li>See screen dimensions in dp, pt, in, sp, px, mm</li><li>Start Dalvik Explorer (third party app)</li><li>Start aLogcat (third party app for viewing logcat)</li><li>Start ManifestViewer (third party app for viewing AndroidManifest.xml ++)</li><li>Start Clean Status Bar (third party app for taking tidying up status bar for screenshots]</li><li>Go directly to the Android 4.3’s permission manager (App Ops)</li><li>Go directly to the device’s developer settings</li><li>Go directly to the list of installed applications</li></ul>
