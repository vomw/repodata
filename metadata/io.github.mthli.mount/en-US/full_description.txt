<p>mount/umount apps that you don’t like on Android, without root.</p><p>You can run an app temporary, when screen off app will be automatically umounted.</p><ul><li>mount: available for use as normal.</li><li>umount: unavailable for use, but the data and actual package file remain.</li></ul><p>Requires Android 5.0 or higher. For setup instructions, please <a href='https://github.com/mthli/Mount' target='_blank' rel='nofollow'>see here</a>.</p>
