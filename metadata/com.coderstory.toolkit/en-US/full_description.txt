<p><i>CorePatch</i> is a powerful Xposed module that helps you to disable signature verification so that you can easily install apps with inconsistent signatures or downgrade them.</p><p><b>NOTE:</b> after v4.9, the package name of this app was changed, so updates are no longer possible. The new owner <a href='https://github.com/LSPosed/CorePatch/issues/155#issuecomment-5017964913' target='_blank' rel='nofollow noopener'>does not want the module listed here anymore</a>, so you'll have to take it directly from Github (or the Xposed Module Repository), without our additional checks and Reproducible Build confirmation. As requested by upstream, we will remove the app here soon.</p>
