<p>For some reason, a lot of manufacturers seem to have a problem with us customizing our own devices, to the point where some disable the built-in Android System UI Tuner.</p>
<p>This app aims to fix that problem, by providing a replacement. For the most part, this is a replica of Android’s System UI Tuner; however, there are a few extra goodies that Android’s solution doesn’t include by default.</p>
<p>Using this app you can:</p><ul>
<li>Control which icons appear in your status bar (not every toggle will work on every device).</li>
<li>Customize Demo Mode.</li>
<li>Control the importance level of notifications (7.0+; doesn’t work well on Samsung).</li>
<li>Enable some hidden features of Android.</li>
<li>Toggle Immersive Mode.</li>
<li>Change Quick Settings options (TouchWiz 7.0 users can change the grid size).</li>
<li>Customize animation speeds.</li>
<li>And so much more.</li></ul>
<p>Most features should work on most devices. Heavily customized OEM versions of Android (such as TouchWiz/Samsung Experience/One UI, EMUI, MIUI, etc) will have fewer available. There is nothing that can be done about this.</p>
<p>If Night Mode gave you a black screen, run this ADB command: <code>adb shell settings delete secure ui_night_mode</code></p>

<p>SystemUI Tuner is not magic! It simply exposes some hidden options in Android. Different manufacturers may remove or change these options, which SystemUI Tuner CANNOT work around. You need to grant some permissions to the app via ADB. ADB Commands for more convenient copy-paste (ADB is not root):</p>
<pre><code>adb shell pm grant com.zacharee1.systemuituner android.permission.WRITE_SECURE_SETTINGS
adb shell pm grant com.zacharee1.systemuituner android.permission.PACKAGE_USAGE_STATS
adb shell pm grant com.zacharee1.systemuituner android.permission.DUMP</code></pre>
