<p><i>CCDroidX</i> ist für Android, was CCMenu für Mac und CCTray für Windows ist. <i>CCDroidX</i> ist ein freies („libre“, wie in „Freiheit“) Überwachungs- und Warntool.</p><p><i>CCDroidX</i> unterstützt alle von <a href='https://cctray.org/v1/' target='_blank' rel='nofollow'>CCTray</a> unterstützten Pipelines. Für eine vollständige Liste sei auf <a href='https://cctray.org/servers/' target='_blank' rel='nofollow'>CCTray Servers</a> verwiesen. Bitte beachten Sie, dass <i>CCDroidX</i> im Moment keine Server unterstützt, die Basic Auth erfordern. Die Funktion wird jedoch in Zukunft verfügbar sein.</p>
