<p><i>CCDroidX</i> is to Android what CCMenu is to Mac and what CCTray is to Windows. CCDroidX is free, as in freedom, build monitoring &amp; alert tool.</p><p><i>CCDroidX</i> supports all pipelines that support <a href='https://cctray.org/v1/' target='_blank' rel='nofollow'>CCTray</a>. See <a href='https://cctray.org/servers/' target='_blank' rel='nofollow'>CCTray Servers</a> for a full list. Do note that <i>CCDroidX</i> does not support servers that requires basic auth for now. The feature will be released in future.</p>
