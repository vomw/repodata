<p><i>Language Selector</i> allows users to set individual app languages. It tries to replicates the behavior of the "App languages" feature introduced in Android 13.</p><p>To use the app you <b>must</b> be on Android 13 or higher, there is no compatiblity with older Android versions. You also <b>must</b> have Shizuku installed.</p><p>Before using this app, you MUST install and start Shizuku, the way this app works makes Shizuku MANDATORY.</p><p><br><b>Features:</b></p><ul><li>Set individual app languages</li><li>Allows selecting language from any app **</li><li>Quick change languages with QSTile</li></ul><p>** Language Selector DOES NOT translate apps, it just specify a locale that will be used by application, if the desired language is supported by the app, it should be displayed as expected.</p><p>** Please note that changing locale for unsupported applications and system apps may cause unexpected behavior and is NOT RECOMMENDED.</p><p><br><b>Language availability:</b></p><p>This app parses Locale (java.util.Locale) from Locale.getAvailableLocales(), consequently, numerous locales are present in the app, the language list is huge, if someone want to improve that, feel free to send a PR, because this way is pretty slow and languages aren't filtered accurately.</p>
