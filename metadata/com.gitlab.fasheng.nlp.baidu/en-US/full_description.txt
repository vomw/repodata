<p><i>Baidu UnifiedNlp Backend</i> is a <a href='https://github.com/microg/android_packages_apps_UnifiedNlp' target='_blank' rel='nofollow noopener'>microG/UnifiedNlp</a> backend that uses <a href='http://lbsyun.baidu.com/index.php?title=android-locsdk' target='_blank' rel='nofollow noopener'>Baidu Location API</a> to resolve locations, which is a popular location service in China. It supports offline location and indoor mode.</p>
<p>Note that Baidu is known to track its users via its SDK (which is used by this app).</p>
