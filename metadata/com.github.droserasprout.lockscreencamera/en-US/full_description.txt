<p><i>Secure Lockscreen Camera</i> is an Xposed module to skip authentication on "Quickly open camera" gesture. It allows the camera to draw activity over lockscreen without invoking Keyguard.</p><p>Tested only with LSPosed, <a href='https://github.com/XEonAX/ANXCamera10' target='_blank' rel='nofollow'>ANXCamera</a> and <a href='https://www.celsoazevedo.com/files/android/google-camera/' target='_blank' rel='nofollow'>GCam port</a>. Other combinations might work, though.</p>
