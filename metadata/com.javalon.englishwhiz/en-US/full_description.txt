<p><i>EnglishWhiz</i> is an offline dictionary app that features fast word look-up.</p><p>With over 177k words available in its offline database built with simple & minimal user interface in mind. The data used in this project was made available by <a href='https://github.com/wordset/wordset-dictionary' target='_blank' rel='nofollow'>this awesome open-source repository</a> (sad to see was abandoned). <i>EnglishWhiz</i> offers some features which include:</p><ul><li>Bookmark</li><li>Text-to-speech</li><li>Search history</li><li>Word suggestions, etc.</li></ul>
