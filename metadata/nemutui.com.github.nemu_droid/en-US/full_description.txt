<p><i>nemu-droid</i> is a remote client for <a href='https://github.com/nemuTUI/nemu' target='_blank' rel='nofollow noopener'>nEMU</a> (Ncurses UI for QEMU). With this app you can remotely start and stop your VMs and also show/edit VM basic settings. Further it can use <a href='https://play.google.com/store/apps/details?id=com.iiordanov.freeaSPICE' target='_blank' rel='nofollow noopener'>aSPICE</a> to connect to virtual machines.</p>
