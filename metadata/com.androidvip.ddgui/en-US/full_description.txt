<p><i>DD GUI</i> is a graphical interface for the good old dd command in a <b>rooted</b> Android environment. Its objective is to facilitate the execution of dd commands by providing a graphical interface. To quickly summarize what can be done with this command, here is a list:</p><ul><li>Backup current system/kernel/recovery/* image to anywhere</li><li>Directly flash a new recovery/kernel (if recovery partition is known and it is a .img file)</li><li>Copy/replace files as root</li></ul><p><b>DISCLAIMER:</b> THIS APPLICATION CAN BE DANGEROUS.
