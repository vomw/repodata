<i>AMap UnifiedNlp Backend</i> is the <a href='https://github.com/microg/android_packages_apps_UnifiedNlp' target='_blank' rel='nofollow noopener'>microG/UnifiedNlp</a> backend that uses <a href='https://lbs.amap.com/api/android-location-sdk/locationsummary' target='_blank' rel='nofollow noopener'>AMap Location API</a> to resolve locations, which is a popular location service in China (but should work in other countries as well). It supports offline location and indoor mode.
