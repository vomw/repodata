<p>In MIUI 13, Xiaomi began using Google Assistant instead of a convenient search application, I did not find an analogue and solved this problem in this way. This small application is designed to be installed as a desktop search, allows you to search and launch other applications.</p><p>In addition to the basic functionality, this application:</p><ul><li>Save the last 5 running applications from it as quick access icons (just like in MIUI 12)</li><li>Search for the entered text on the Internet, using Yandex (by default) or Google.</li><li>Search in contacts</li><li>Uses cache for fast open</li></ul><p>For details on usage with Xiaomi.EU ROMs and other hints, please see the app's README.</p>
