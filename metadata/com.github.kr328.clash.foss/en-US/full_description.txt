<p><i>Clash for Android</i> is a user interface of clash which is a rule-based network tunnel.</p><p><br><b>Features:</b></p><ul><li>Local HTTP/HTTPS/SOCKS server with/without authentication</li><li>VMess, Shadowsocks, Trojan (experimental), Snell protocol support for remote connections. UDP is supported.</li><li>Built-in DNS server that aims to minimize DNS pollution attacks, supports DoH/DoT upstream. Fake IP is also supported.</li><li>Rules based off domains, GEOIP, IP CIDR or ports to forward packets to different proxy</li><li>Remote groups allow users to implement powerful rules. Supports automatic fallback, load balancing or auto select proxy based off latency</li><li>Remote providers, allowing users to get proxy/rule lists remotely instead of hardcoding in config</li></ul>
