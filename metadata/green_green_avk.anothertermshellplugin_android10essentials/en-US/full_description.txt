<p>This plugin for <i><a href='https://github.com/green-green-avk/AnotherTerm' target='_blank' rel='nofollow'>Another Term</a></i> has been created in order to still be able to run Linux applications in the <b>PRoot</b> environment on Android 10 (API 29) and higher. It can also be used with any API &gt;= 21 for convenience. The implemented approach is not different from <a href='https://github.com/CypherpunkArmory/UserLAnd' target='_blank' rel='nofollow'>UserLAnd</a> but separating it into a plugin seems more convenient.</p><p>Details on the “Linux under PRoot” feature and Android 10 <a href='https://green-green-avk.github.io/AnotherTerm-docs/local-shell-w-x.html#main_content' target='_blank' rel='nofollow'>can be found here</a>.</p><p>The plugin currently contains minitar (for extracting <code>.tar.gz</code>/<code>bz2</code>/<code>xz</code>) and <b>PRoot</b>. Call without arguments for usage details.</p>
