<p><i>HomeBerry</i> is a simple Android app that allows you to control your Raspberry PI through a REST API. Please note, that you must install this API on the Pi. For that, please check out the <a href='https://github.com/AmkSk/homeberry-api' target='_blank' rel='noindex'>HomeBerry API</a> repository.</p><p><br><b>App features:</b></p><ul><li>Simple and nice interface for calling requests (HTTP GET)</li><li>Settings screen for creating / editing existing requests</li><li>Option to import / export your configuration to a json file</li><li>Android App Shortcuts - launch your requests directly from the launcher (only first four requests will show up)</li></ul>
