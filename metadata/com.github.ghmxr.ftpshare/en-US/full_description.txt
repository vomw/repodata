<p><i>FTP Share</i> is a file sharing application based on the Apache FTP server component.</p><p><b>Features:</b></p><ul><li>You can use anonymous mode to log in, specify the shared main path and set the write permission;</li><li>Several users can be set, and the shared main path and write permission can be specified separately;</li><li>You can set the main path to external storage (due to different Android versions and device models, the actual use may be different);</li><li>You can choose to disconnect FTP service automatically in some cases, such as when WiFi connection is disconnected, when hotspot is disconnected, after a specified time;</li><li>Dark mode, Chinese and English support.</li></ul><p><b>About external calls to the FTP service:</b></p><p>The FTP service of this application is exposed to outside. If you want to start the FTP service of this application through other applications or automation applications such as Tasker, you can do so by calling an intent (see project page for details).</p>
