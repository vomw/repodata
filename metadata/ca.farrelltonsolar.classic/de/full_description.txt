<p><i>Classic Monitor</i> ist ein Statusmonitor für die <a href='https://www.midnitesolar.com/' target='_blank' rel='nofollow noopener'>Midnite Solar</a>'s Classic 150, 200 und 250 Laderegler. Das Programm liest die Daten nur aus.</p><p>Die Software wird so wie sie ist bereitgestellt, ohne irgendeine Garantie, weder ausdrücklich noch stillschweigend.</p><p><i>Classic Monitor</i> ist kein Produkt von Midnite, auch keine Unterstützung seitens Midnite.</p><p>Erkennt die App einen aktuellen Whizbang Junior Strommonitor, erscheint der Status in der bi-direktionalen Stomanzeige. Unterstützung für die Tristar MPPT Laderegler von Morningstar ist ebenfalls in den Grundfunktionen enthalten. Aufgezeichneten Protokolle können an pvoutput.org weitergeleitet werden, eine API-Key und SID ist in den Einstellungen für jeden Laderegler anzugeben.</p><p>Dies ist die „stabile App-Variante“. Für Interessierte gibt es auch eine Version mit <a href='fdroid-app:ca.classicdiy.classic'>experimentellem MQTT-Support</a>.</p>
