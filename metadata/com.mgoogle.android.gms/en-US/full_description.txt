<p>microG GmsCore is a FLOSS (Free/Libre Open Source Software) framework to allow applications designed for Google Play Services to run on systems, where Play Services is not available.</p><p>This fork tweaks MicroG to be usable by applications that require Google authentication such as Vanced.</p><p><b>Notable changes:</b></p><ul><li>No longer a system app</li><li>Package name changed from <code>com.google.android.gms</code> to <code>com.mgoogle.android.gms</code> to support installation alongside the official MicroG</li><li>Removed unnecessary features</li><li>Removed all permissions, as none are required for Google authentication</li></ul><blockquote><b>Note:</b> microG (and so this fork of it) provides FOSS replacements for proprietary libraries in order to make apps which depend on such work. So a scanner will find the names used by those original, proprietary libraries as if they were there (which is how the apps needing them find them). Still the app won't be marked with the corresponding AntiFeatures, as those would apply to the original libraries only. <code>NonFreeNet</code> is still applied for Google authentication. <code>Tracking</code> is not, as Firebase Analytics here is just a stub (an „empty shell“ without functionality).</blockquote>
