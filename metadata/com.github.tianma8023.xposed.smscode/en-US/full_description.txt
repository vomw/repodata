<p><i>XposedSmsCode</i> is an Xposed Module which can recognize, parse verification code and copy it to clipboard when a new message arrives. It can also input SMS code automatically.</p><p><br><b>Features:</b></p><ul><li>Copy verification code to clipboard when a new message arrives.</li><li>Show toast when the verification code is copied.</li><li>Show notification when verification SMS parsed.</li><li>Mark verification SMS as read(experimental).</li><li>Delete verification SMS when it's extracted successfully(experimental).</li><li>Block verification SMS if it's extracted successfully.</li><li>Custom keywords about verification code message (regular expressions allowed).</li><li>Support the SMS code match rules customization, importation and exportation.</li><li>Auto-input SMS code.</li><li>Various theme color to choose.</li></ul>
